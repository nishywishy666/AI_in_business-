# Lessons

A log of mistakes, bugs, and surprising failures, written *after* they're resolved, so the same error isn't repeated later in the hackathon (or by a future Claude session that wasn't there when it happened).

## Convention
- File name: `NNNN-short-kebab-slug.md`, numbered sequentially starting at `0001`.
- Use [TEMPLATE.md](TEMPLATE.md) as the starting point.
- Write it as soon as the issue is resolved, while the root cause is still fresh — not days later from memory.
- One lesson per distinct root cause. If the same root cause bites twice, don't duplicate — link back to the existing lesson and note it recurred.
- Before starting work in an area, skim this folder for anything relevant.
