# Plans

A record of intended changes, written *before* the work starts, so anyone (including a future Claude session) can see what was attempted, why, and whether it worked.

## Convention
- File name: `NNNN-short-kebab-slug.md`, numbered sequentially starting at `0001`.
- Use [TEMPLATE.md](TEMPLATE.md) as the starting point.
- Write it before starting the work described. Update **Status** and **Outcome** as the work progresses — don't leave a plan permanently "In Progress" once it's done or abandoned.
- One plan per non-trivial change. Trivial fixes and pure exploration don't need one.

## Status values
- `Proposed` — written, not yet started
- `In Progress` — actively being worked on
- `Done` — completed as planned
- `Abandoned` — not pursued; note why in Outcome
- `Superseded by NNNN` — replaced by a later plan
